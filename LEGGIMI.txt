HELP DESK INAIL - Registro interventi, utenti, stampanti e toner
================================================================

SE HAI GIA' IL REPOSITORY SU GITHUB (aggiornamento)
1. Apri il repository > clicca helpdesk.py > icona matita > cancella tutto e incolla il nuovo
   helpdesk.py > Commit changes.
   (oppure: Add file > Upload files, trascina i nuovi file e conferma: sostituisce quelli vecchi)
2. Add file > Upload files: carica anche il NUOVO file printer_images.py. Commit changes.
3. Il workflow (.github/workflows/build.yml) NON cambia.
4. Scheda Actions: il .exe si ricrea da solo. Scarica il nuovo "HelpDeskINAIL" da Artifacts.
I dati gia' inseriti restano: l'app li aggiorna da sola al primo avvio.

PRIMA INSTALLAZIONE
Carica tutti i file di questa cartella (compresa .github/workflows/build.yml) in un repository.

DOVE SONO I DATI
%APPDATA%\HelpDeskINAIL  (da programma: File > Apri la cartella dei dati).
Backup: File > Salva una copia di backup.
