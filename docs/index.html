Scambio con il PC

Dal telefono al PC

Crea un file con gli interventi, le foto, i cambi toner, gli interventi del tecnico, i verbali (con foto e firme) e gli utenti nuovi o modificati. Mandalo al PC (posta aziendale, AirDrop…) e nel programma usa File › Importa dati dal telefono.

Dal PC al telefono

Nel programma del PC usa File › Esporta dati per il telefono, poi scegli qui quel file. Arrivano utenti (con la matricola), interventi, verbali, edificio, stampanti, cambi toner, interventi del tecnico e scorta toner del PC (con le foto, se le hai incluse). Quello che c'è già sul telefono non viene duplicato; se c'è una modifica più recente vince quella.

Ripristina da una copia

Se hai perso i dati del telefono, scegli qui un file «Tutto» creato in precedenza.
I dati restano solo su questo telefono, finché non crei un file. Fai ogni tanto un invio «Tutto» al PC: se cancelli l'app o resetti l'iPhone, i dati non inviati si perdono. Per i file con dati dei dipendenti usa i canali consentiti dall'INAIL.
